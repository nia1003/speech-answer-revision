### A. GSM8K MSS 有沒有被沒重述答案灌水
GSM8K 的 MSS 主要判分是第二輪，所以要檢查 non-answer 是否灌水了 MSS。

| | 第二輪 MSS | 強制 MSS | 第二輪 non-answer | non-answer 中被判錯 |
|---|---|---|---|---|
| 文字 | 261/687 = 38.0% | 220/687 = 32.0% [28.6, 35.6] | 9/687 = 1.3% | 8/9 |
| 語音 | 119/589 = 20.2% | 59/589 = 10.0% [7.8, 12.7] | 20/589 = 3.4% | 20/20 |

- GSM8K Invalid 的 non-answer 很少，所以第二輪到強制答案的下降，大部分不是 non-answer 造成的。
  - 文字：r2-only 44 題，其中 non-answer 只有 8 題。
  - 語音：r2-only 64 題，其中 non-answer 只有 20 題。
- 改用強制答案後，語音 − 文字的差距沒有縮小，反而變大：
  - 同題 N = 548：語音 51 題、文字 171 題，差 −21.9 個百分點。
  - 只有語音判錯 17 題、只有文字判錯 137 題，Holm p 1.7e-23。
  - 第二輪判分下是 −17.9。
- 所以 GSM8K「語音 MSS 較低」不是兩個模態 non-answer 率不同造成的。

### 解讀（探索性）
- 兩邊都用強制答案時，四個資料集 × 模態的操縱檢查方向都正確。
  - Invalid 比 Unsupported 更常讓模型改錯。
  - Valid 比 Unsupported 更常讓模型改對。
  - 但語音的幅度小很多：GSM8K MSS − C→W 是 +9.0（文字 +31.1），MuSiQue 是 +4.4（文字 +31.2）。
- 語音的 MSS 與 CRS 都比文字低：
  - GSM8K MSS −21.9，CRS −10.0（CRS 的 n = 80，沒有偵測到差異）。
  - MuSiQue MSS −24.4。
  - 兩者一起下降，比較像語音證據的整體影響力較低，而不是語音比較能辨別證據對錯。
  - 這與上面第 3 點的保留一致。
- 給後續模型的建議：
  - 其餘四個模型的結果還沒看過。若要把 M1 改成兩邊都用強制答案，應在跑之前寫進新的 PREREG。
  - 對 Qwen 而言，這個版本只能算探索性。
